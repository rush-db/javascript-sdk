Background file imports and SaaS connections (RushDB Cloud only). `db.imports` creates an import with its files, uploads them (`s3-multipart`: parts to presigned URLs in parallel, default 4 at a time, each retried, completed with their ETags; `direct`: the bytes through the API), previews the mapping, starts the run and follows it (`get`, `list`, `wait`, `cancel`, `retry`, `delete`); `importFiles` does it all in one call with mappings, links between files and progress. Upload data can be a `Blob`/`File`, bytes, a web `ReadableStream` or a Node `Readable`. Previews flag columns that look like personal data (`pii`, `suggestion: 'include' | 'skip' | 'hash'`), and a file mapping can keep columns as a keyed hash (`hash`). `db.connections` lists the connector catalog and Zapier/Make/n8n push templates (`pushTemplates`) and manages connections (`create`, `update`, `delete({ deleteData })`, `test`, `preview`, `sync`, `runs`, `pause`, `resume`, `rotateWebhookToken`). Each stream has a field `policy` (`auto` or `allowlist`, with `include`/`exclude`/`hash`), `reviewed` and `unreviewed`; `fields` profiles a stream's fields with personal-data findings and `reviewFields` saves the choices as an allowlist. Agent connections (`connectorId: 'agent'`) return an `agentToken` once and report their status in `connection.agent`. The DTO types are exported, and both namespaces are listed in `CLOUD_ONLY_METHODS`. The HTTP clients accept a raw `rawBody` for uploads.
